Use [Configuration](/docs/configuration) for shared `package.json` settings. Install `react-native-nitro-sqlite` and `react-native-nitro-modules`, then install Pods and rebuild:

```sh
cd macos && pod install
```

Databases use an app-specific Application Support directory. See [file locations](/docs/guides/database-lifecycle#file-location-and-prepopulated-databases) for the `location` option. Sandboxed apps can access only their permitted containers.

## Apple build options

Use the [iOS build options](/docs/configuration/ios#bundled-or-system-sqlite), running CocoaPods from `macos`.

For vector search, install `react-native-nitro-sqlite-vec` and run `NITRO_SQLITE_VEC=1 pod install` from `macos`. Rebuild and follow the [vector search guide](/docs/integrations/vector-search).

## Run the example

The repository example requires macOS 14 or later. Install its workspace and Ruby dependencies, then run the `pods:macos` and `macos` scripts. To run Metro separately, use the `start` script and pass `--no-packager` to `macos`. For a release build, pass `--mode Release --no-packager`.
