---
title: Your first database
description: Open a SQLite file, create a table, and insert and read a row with bound parameters.
---

`open()` returns a connection bound to one database name. If the file does not exist, SQLite creates it in the app's database directory. Keep the connection while you use the database, and close it when you are done.

```ts
import { open } from 'react-native-nitro-sqlite'

const db = open({ name: 'app.sqlite' })

db.execute(`
  CREATE TABLE IF NOT EXISTS notes (
    id INTEGER PRIMARY KEY,
    body TEXT NOT NULL
  )
`)

const body = 'Read the docs'
db.execute('INSERT INTO notes (body) VALUES (?)', [body])

const { results } = db.execute<{ id: number; body: string }>(
  'SELECT id, body FROM notes WHERE body = ?',
  [body],
)

console.log(results)
db.close()
```

The `?` placeholder binds `body` as a value. Use parameters for data supplied by a user or another untrusted source. The generic row type documents the expected shape for TypeScript; it does not validate values at runtime. You can also read rows through `rows._array`, `rows.length`, and `rows.item(index)`.

For work that should not run on the JavaScript thread, use `await db.executeAsync(...)`. See [sync and async](/docs/getting-started/sync-and-async) before mixing the two forms, and [parameters and results](/docs/guides/parameters-and-results) for result details.
