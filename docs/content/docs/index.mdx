---
title: Nitro SQLite
description: SQLite for React Native through Nitro Modules, with synchronous and asynchronous queries.
---

Nitro SQLite gives React Native apps a local SQLite database on iOS and Android. It exposes synchronous and asynchronous queries, parameter binding, transactions, batch writes, and a connection API that keeps operations on one database in order.

Start with [installation](/docs/getting-started/installation), then [create your first database](/docs/getting-started/first-database). The examples use the `open()` connection API.

## Find the task you need

| Task | Read |
| --- | --- |
| Choose between synchronous and asynchronous calls | [Sync and async](/docs/getting-started/sync-and-async) |
| Bind values and inspect query results | [Parameters and results](/docs/guides/parameters-and-results) |
| Make several changes atomically | [Transactions](/docs/guides/transactions) or [batch operations](/docs/guides/batch-operations) |
| Open an existing file or remove a database | [Database lifecycle](/docs/guides/database-lifecycle) |
| Query across database files | [Attach databases](/docs/guides/attach-databases) |
| Import a line-oriented SQL script | [Load a SQL file](/docs/guides/load-sql-file) |
| Move from react-native-quick-sqlite | [Migration guide](/docs/guides/migrate-from-quick-sqlite) |

For method signatures, see the [API reference](/docs/api). Native storage options live in the [iOS](/docs/configuration/ios) and [Android](/docs/configuration/android) configuration pages. There are separate guides for [TypeORM](/docs/integrations/typeorm) and [vector search](/docs/integrations/vector-search).
